# Hood Inu website

Open dist/index.html to view the finished static website. No install or build is needed.

The live chart and token purchase links are placeholders at the user's request. Edit dist/config.js to add the official contract, Uniswap token link, and Dexscreener pair URL. Once a valid pair URL is set, the chart area automatically uses only the Dexscreener embed. X defaults to https://x.com/.

All 15 original scene illustrations are in dist/assets/generated. Their generation prompts are stored alongside the source artwork in ../assets/generated/prompts.json. The original banner appears exclusively in the Join Us section at 3:1. Official platform SVGs were copied from S2/ZHOOD/icons and recolored with CSS. All three supplied PNGs are used; the source folder contained no videos.

Motion includes floating artwork, orbiting rings, an animated text band, drifting particles, scroll reveals, progress tracking and hover effects. Reduced-motion preferences are respected. The artwork viewer supports keyboard navigation and Escape.
